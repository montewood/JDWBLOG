# 개인정보 및 쿠키 안내

JDW Blog는 사이트 이용 현황을 이해하고 대용량 웹 대시보드의 트래픽을 관리하기 위해 제한적인 분석 정보와 브라우저 저장소를 사용합니다.

## Google Analytics 및 Google Tag Manager

본 사이트는 Google Tag Manager 컨테이너 `GTM-P8STCFM`을 통해 Google Analytics 4를 사용할 수 있습니다.

Google Analytics는 다음과 같은 정보를 처리할 수 있습니다.

- 방문 페이지, 방문 시각, 체류 및 상호작용 정보
- 브라우저·기기·운영체제의 일반적인 기술 정보
- 대략적인 지역 및 네트워크 정보
- 사용자를 구분하기 위한 무작위 식별자

GA4는 일반적으로 다음 퍼스트파티 쿠키를 사용합니다.

- `_ga`: 사용자를 구분하기 위해 사용하며 기본 만료 기간은 2년입니다.
- `_ga_*`: 세션 상태를 유지하기 위해 사용하며 기본 만료 기간은 2년입니다.

Google이 처리하는 정보는 Google의 서버에서 국외 처리될 수 있습니다. 구체적인 처리 방식은 [Google 개인정보처리방침](https://policies.google.com/privacy)과 [GA4 쿠키 안내](https://support.google.com/analytics/answer/11397207)를 참고해 주세요.

본 사이트는 현재 별도의 분석 쿠키 동의 배너를 제공하지 않습니다. 브라우저의 쿠키 차단·삭제 기능 또는 [Google Analytics 차단 브라우저 부가기능](https://tools.google.com/dlpage/gaoptout)을 이용해 분석을 거부할 수 있습니다.

## 방문자 대시보드 집계 정보

홈 화면에 표시되는 방문자 차트는 GitHub에 공개된 날짜별 집계 JSON을 읽습니다. 해당 파일은 날짜별 Active Users와 같은 집계값만 포함하며 개인별 방문 기록이나 사용자 식별자를 공개하지 않습니다.

## Shinylive 대시보드 실행 제한

Shinylive 웹 대시보드는 브라우저에서 R과 webR을 실행하므로 일반 페이지보다 큰 파일을 다운로드합니다. 안정적인 트래픽 관리를 위해 하루 실행 횟수를 제한합니다.

이 기능은 다음 정보를 사용합니다.

- `sessionStorage`의 무작위 세션 ID: 같은 탭 세션에서 재실행할 때 횟수를 중복 차감하지 않기 위해 사용하며 탭 세션이 끝나면 삭제됩니다.
- `jdw_dashboard_access` 기능성 쿠키: 허용된 대시보드 실행을 확인하기 위해 사용하며 HttpOnly로 저장되고 약 30분 후 만료됩니다.
- 서버의 해시된 세션 키와 일일 실행 횟수: 중복 차감 방지와 전역 상한 적용을 위해 Upstash Redis에 최대 48시간 보관됩니다.

원본 세션 ID는 서버 저장소에 보관하지 않으며, 해시된 값은 광고나 방문자 분석에 사용하지 않습니다. 이 저장소와 쿠키는 사용자가 요청한 대시보드 기능 제공과 트래픽 보호를 위한 기능성 정보입니다.
